## 🎨 圖標生成指南

### 快速生成圖標
1. 在瀏覽器中打開 `create-icons.html`
2. 點擊「生成所有圖標」按鈕
3. 點擊「批量下載」或單獨下載每個圖標
4. 將下載的圖標文件放在遊戲根目錄中

### 需要的圖標文件
- `favicon.ico` (32×32) - 瀏覽器標籤圖標
- `favicon-16x16.png` (16×16) - 小尺寸圖標
- `favicon-32x32.png` (32×32) - 標準圖標
- `apple-touch-icon.png` (180×180) - iOS 設備圖標
- `android-chrome-192x192.png` (192×192) - Android 圖標
- `android-chrome-512x512.png` (512×512) - 高解析度圖標
