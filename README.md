# 🥷 火柴人魔法亂鬥 — NinjaPlay

一款可直接在瀏覽器遊玩的雙人火柴人忍者格鬥遊戲，不需要安裝依賴或建置。

## 🎮 特色

### 二十名可選忍者
- 元素系、刺客系、控制系、近戰系與遠程系共 20 名忍者。
- 每位忍者都有普攻、小招、奧義與獨立的動作／命中特效。
- 可進行一般對戰、CPU 對戰與三戰兩勝的「道場鬥技盃」選角賽制。

## 本機啟動與檢查

請看 [PROJECT_STATUS.md](PROJECT_STATUS.md)。其中記錄了目前應修改的檔案與每次修改前可執行的檢查。

角色平衡方式與目前的調整紀錄在 [BALANCE.md](BALANCE.md)。日後改數值只要編輯 `balance.js`，不需要進入戰鬥引擎。
