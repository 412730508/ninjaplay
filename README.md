# 🥷 火柴人魔法亂鬥 — NinjaPlay

一款可直接在瀏覽器遊玩的雙人火柴人忍者格鬥遊戲，不需要安裝依賴或建置。

## 🎮 特色

### 七大忍者流派
- 🌪️ **風影忍者** - 疾風如電，閃避大師
- 🔥 **火焰忍者** - 爆炎衝刺，烈焰印記
- 🌊 **水影忍者** - 水幕護盾，控制專家
- ⚡ **雷擊忍者** - 極速連擊，閃電之力
- 🗿 **岩甲忍者** - 地裂震撼，防禦堡壘
- 🌑 **暗影忍者** - 黑刃突襲，暴擊刺客
- 👻 **靈忍者** - 靈天審判，神聖治療

## 本機啟動與檢查

請看 [PROJECT_STATUS.md](PROJECT_STATUS.md)。其中記錄了目前應修改的檔案、保留的歷史修復檔，以及每次修改前可執行的檢查。

角色平衡方式與目前的調整紀錄在 [BALANCE.md](BALANCE.md)。日後改數值只要編輯 `balance.js`，不需要進入戰鬥引擎。
